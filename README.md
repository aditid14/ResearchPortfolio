# Aditi Deshpande – Computational Biology / Quantitative Research Portfolio

This repository contains selected coursework and research projects in computational biology, bioinformatics, and quantitative modeling. These materials highlight my experience analyzing high-dimensional biological datasets, implementing computational workflows, and applying quantitative methods to cancer research.

## Contents

### Research Projects

1. **SURF Breast Cancer Project** (`SURF.ipynb`)
   - Summer Undergraduate Research Fellowship (SURF) project at the Purvis Lab, UNC Chapel Hill.
   - Investigating heterogeneity among breast cancer cells exposed to palbociclib, a CDK4/6 inhibitor.
   - Applying computational preprocessing and clustering approaches to characterize cell populations using spatial protein-expression data.

2. **CaRSIP Prostate Cancer Proteomics Research** (`CaRSIP Research Presentation.pdf`)
   - Summer 2026 Cancer Research Summer Internship Program (CaRSIP) project at the Cieslik Lab, University of Michigan.
   - Analyzing large-scale CPTAC prostate cancer proteomics data to investigate molecular patterns associated with prostate cancer.
   - Conducting initial exploratory analyses followed by a more focused investigation of protein ubiquitination and cancer-related molecular pathways.
   - Presented research findings and analytical approaches as part of the summer internship program.
   - Code and data are not public pending publication.

3. **Tumor-Normal Differential Transcriptomics** (`Differential Transcriptomics and Pathway Analysis of Tumor versus Normal Colorectal Tissue (4).pdf`)
   - Functional Genomics course project.
   - Comparing gene-expression profiles between colorectal tumor and normal tissue using DESeq2.
   - Applying pathway enrichment methods to investigate biological processes associated with tumor tissue.

4. **Tumor-Normal-Immune Mathematical Modeling** (`Tumor-Normal-Immune Math Modeling (1).pdf`)
   - UNC Direct Research Program project.
   - Mathematical modeling of tumor progression and immune response using differential equations.
   - Exploring interactions among tumor, normal, and immune cell populations through quantitative modeling.

### Code Files

- **`SURF.ipynb`** – Jupyter Notebook for breast cancer computational analyses, including data preprocessing and clustering workflows.
- **`DRP_treatment.m`** – MATLAB code for the tumor-normal-immune mathematical modeling project.

### Skills Demonstrated

- Programming in Python, R, and MATLAB.
- Data analysis and statistical modeling.
- High-dimensional biological data analysis, including transcriptomics and proteomics.
- Differential expression analysis using DESeq2 and pathway enrichment methods.
- Machine learning and unsupervised analysis, including clustering and dimensionality reduction.
- Mathematical modeling using differential equations.
- Computational workflows, data visualization, and reproducible research.

- Open `SURF.ipynb` in JupyterLab, Jupyter Notebook, or GitHub's notebook viewer to explore the breast cancer computational analysis.

- Open the corresponding PDF reports and presentation to review the transcriptomics, mathematical modeling, and prostate cancer proteomics projects.
